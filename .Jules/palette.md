## 2026-08-04 - [Modal Reset and Form Accessibility Patterns]
**Learning:** Proper modal state isolation is crucial in React to prevent forms retaining stale inputs or validation styles after being dismissed. Using a dynamic component `key` prop tied to the open/close state solves this elegantly without manual state resets inside synchronous hooks. Furthermore, form fields must have explicitly linked `htmlFor` and `id` attributes, alongside `aria-required="true"` and `role="dialog"` to ensure screen readers properly convey field contexts to assistive technologies.
**Action:** Always key modal components dynamically using their open status (e.g. `key={isOpen ? 'open' : 'closed'}`) to trigger a clean remount, and strictly match every `<label>` with its companion `<input>` using descriptive `htmlFor` and `id` attributes.
