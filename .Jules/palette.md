## 2026-03-06 - Accessible Modal Dialog & Simulated Form Submission Delay
**Learning:** Modal components must implement proper ARIA landmark roles ('role="dialog"'), associate titles via 'aria-labelledby', and map labels to inputs with unique 'id' values to avoid substring matching issues in strict screen readers and testing frameworks. Furthermore, introducing a simulated network delay (e.g., 800ms) with a disabled loading state on submission buttons significantly enhances micro-UX and prevents accidental double-submission bugs.
**Action:** Always map labels using 'htmlFor' with explicit ID suffixes, set 'aria-required="true"' on mandatory inputs, disable interactive elements during async actions, and add an active spinner to make the application feel robust and reactive.
